# Integration Note: MC ↔ OpenClaw (2026-08-21 06:52 MDT)

## David's rule (verbatim, 2026-08-21)

> "When working on Miracle Claw, any change in the CLI is in the integrated
> MC-Openclaw be sure to make a memory note of that."

## What this means

**Miracle Claw IS the integrated MC-OpenClaw build.** There is no separate
"CLI project" — when I see a CLI change, it's a change to the integrated
build, not a side project.

## The folder (the one that matters)

**`/home/adeal/.openclaw/workspace/projects/miracle-claw/`**

This is the source tree where:
- `src-tauri/` — Rust/Tauri shell that produces `miracle-claw.exe`
  - `src-tauri/src/` — Rust source (lib.rs, auth/, tools/, etc.)
  - `src-tauri/binaries/` — CLI sidecars (`miracle-claw-launcher.exe`,
    `miracle-claw-tools.exe`, and the linux-gnu triplesthat get bundled into
    the MSI/NSIS installer)
  - `src-tauri/resources/` — bundled OpenClaw runtime (regenerated by
    `scripts/bundle-runtime.sh`)
- `src/`, `depot/`, `index.html` — the frontend that gets bundled into the EXE
- `scripts/` — build orchestration
  - `build-windows-docker.sh` — `cargo-xwin` cross-compile → NSIS installer
  - `bundle-runtime.sh` — patches the openclaw runtime into `src-tauri/resources/`
  - `patch-openclaw-dist.sh` — runtime patches
- `dist-installers/windows/` — NSIS installers (also copied to
  `/mnt/c/Users/Adeal/Desktop/MiracleClaw_<ver>_x64-setup.exe`)
- `notes/` — THIS folder. Project-internal design notes & tidbits.
- `STATUS.md`, `CHANGELOG.md` — project state

## Anti-pattern remembered

DON'T do this:
- "There's a CLI change, let me create a new project folder for it"
- "Let me clone the OpenClaw repo and work on the CLI there"
- "CLI work goes in `/home/adeal/Projects/miracle-claw-extras/`"

DO this:
- All CLI work lives in `/home/adeal/.openclaw/workspace/projects/miracle-claw/src-tauri/`
- If it's a CLI binary change → edit `src-tauri/src/*.rs` or `src-tauri/binaries/`
- After changes, rebuild via `scripts/build-windows-docker.sh`
- Note CLI changes in `notes/CLI-CHANGES.md` (see notes/README.md)

## Why this matters

Because MC IS the OpenClaw CLI plus the Tauri wrapper. The integration
boundary is `package.json` + `src-tauri/Cargo.toml` + the bundled runtime.
Adding a new CLI command means:

1. Add the Rust `#[tauri::command]` in `src-tauri/src/*.rs`
2. Register it in `lib.rs` invoke_handler
3. Wire the JS side in `src/` if it needs a UI
4. Update `CHANGELOG.md` + `STATUS.md` + drop a `notes/` tidbit
5. Rebuild via `scripts/build-windows-docker.sh`

There's no separate CLI codebase. The CLI === the Tauri commands.
