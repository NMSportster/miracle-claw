## What HomeBot owns

1. **Live MAIC plugin on your gateway** —
   `/home/steeler/.openclaw/extensions/maic/`
   This stays as your running config; it's the canary for new MAIC versions.

2. **MC depot source** —
   `/home/adeal/.openclaw/workspace/projects/miracle-claw/depot/maic-plugin/`
   Mirror your live plugin here whenever MAIC ships a new version. Use
   `rsync --delete` or a SHA-based check.

3. **Version + integrity metadata** —
   - `depot/maic-plugin/VERSION` — bump to match new MAIC release
   - `depot/maic-plugin/SHA256SUMS` — keep so `bundle-runtime.sh` can re-stage

## What HomeBot does NOT own

- **MC's bundled runtime copy** at
  `/home/adeal/.openclaw/workspace/projects/miracle-claw/src-tauri/resources/maic-plugin/`
  That's only regenerated by `bundle-runtime.sh` on the build host.

- **MC's state-dir copy** at `<userStateDir>/extensions/maic/`
  That's written by MC's `copy_maic_plugin_if_needed` SHA-checked copy
  during first-run. Different users, different state dirs.

## Workflow after each MAIC release

```bash
# On steeler (HomeBot's box)
MAIC_VER="0.X.Y"   # whatever MAIC just shipped

# 1. Update your live plugin
#    (MAIC ships via its own update channel; your existing process)

# 2. Mirror to MC depot
rsync -av --delete \
  /home/steeler/.openclaw/extensions/maic/ \
  /home/adeal/.openclaw/workspace/projects/miracle-claw/depot/maic-plugin/

# 3. Bump version file
echo "$MAIC_VER" > \
  /home/adeal/.openclaw/workspace/projects/miracle-claw/depot/maic-plugin/VERSION

# 4. Generate SHA256SUMS for the 4 files in the plugin dir
cd /home/adeal/.openclaw/workspace/projects/miracle-claw/depot/maic-plugin
sha256sum index.js openclaw.plugin.json package.json test_plugin.js \
  > SHA256SUMS

# 5. Restart your gateway and verify MAIC still works
pkill -9 -f "openclaw.mjs gateway"
sleep 1
rm -rf ~/.openclaw/logs/stability/   # reset restart-loop breaker
nohup openclaw gateway --port 18789 --bind loopback --auth none \
  > /tmp/homebot-gw.log 2>&1 &
disown
sleep 10
curl -sI http://localhost:18789/v1/models   # → 200 OK
grep -i "maic" /tmp/homebot-gw.log | head -3   # → MAIC plugin loaded

# 6. Drop a status note in MC's STATUS.md so I see it next sync
cat >> /home/adeal/.openclaw/workspace/projects/miracle-claw/STATUS.md <<EOF

## MAIC plugin updates

- $(date +%Y-%m-%d) — bumped to $MAIC_VER (verified on HomeBot gateway)
EOF
```
